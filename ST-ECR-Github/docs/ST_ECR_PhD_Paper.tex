\begin{abstract}
% ============================================================
Predictive modeling in non-stationary financial environments faces a persistent
structural challenge: the tradeoff between accurate point estimates—required for
profitability—and reliable uncertainty quantification—required for risk calibration.
Existing spatio-temporal architectures entangle these objectives by processing
temporal and spatial dependencies through shared latent bottlenecks, producing
models that are simultaneously overconfident and underperforming during
regime shifts.

We propose \textbf{Spatio-Temporal Epistemic Claim Retrieval (ST-ECR)}, a
selective-prediction and risk-calibrated decision framework that decomposes
non-stationary forecasting into three orthogonal modules acting on distinct
failure modes: (1)~a \emph{Temporal Transformer} with \emph{Dynamic Graph
Attention} for representation adaptation; (2)~an \emph{Episodic Trajectory
Memory} functioning strictly as a calibration stabilizer; and (3)~an
\emph{empirically calibrated Conformal Abstention Gate} for selective execution.
Epistemic uncertainty $\sep$ drives a tri-level routing policy: memory query
decisions, abstention decisions, and position-sizing decisions are each governed
by distinct uncertainty estimates, eliminating cross-objective interference.

We conduct a 5-arm factorial controlled intervention study that isolates the
mechanistic effect of every component.  Our key empirical findings are:
(i)~episodic memory is a \emph{calibration stabilizer}—it reduces ECE
independently of Sharpe ratio;
(ii)~conformal gating resolves the ``conformal paradox'' by improving decision
selectivity at the cost of marginal calibration degradation on the
\emph{retained} distribution;
(iii)~Max Drawdown (MaxDD) increases are a structural sparsification effect
induced by breadth reduction, not directional error accumulation.
On the spatial forecasting benchmark, ST-ECR's routed variant achieves
a test loss of $0.2380$, improving over PredRNN++ ($0.2456$) and STFAGLU
($0.2795$), while the full ST-ECR (Rev) attains $0.2140$—a $12.9\%$
reduction relative to the strongest baseline.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

The allocation of capital across a universe of $N$ assets under distributional
non-stationarity requires two properties that are in structural tension: a model
must be \emph{sharp}—its conditional mean must track regime-dependent return
dynamics—and it must be \emph{calibrated}—its predicted uncertainty must match
empirical coverage so that position sizes and abstention decisions are well-founded.
Standard spatio-temporal architectures such as Graph WaveNet
\citep{wu2019gwn}, Temporal Fusion Transformer (TFT) \citep{lim2021tft}, and
PatchTST \citep{nie2022patchtst} encode temporal dependencies via shared
recurrent or attention layers, then propagate through a static or learned
graph.  Under stationarity these models are competitive.  Under regime
shifts—volatility clustering, correlation breakdowns, liquidity crises—their
epistemic uncertainty $\sep$ inflates precisely when calibration is most critical,
yet no mechanism exists to distinguish this inflation from aleatoric noise
$\sal$ or to route computation accordingly.

A na\"ive response is to stack mechanisms: add an online learning layer to
catch drift, an episodic memory to retrieve context, a post-hoc conformal
wrapper to bound tail risk.  But stacked mechanisms interact destructively
when they share the same latent bottleneck: memory retrieval that is routed by
aleatoric uncertainty will retrieve irrelevant context; a conformal gate trained
jointly with position sizing will trade calibration for profitability silently.
The result is a system that appears to tick all architectural boxes yet remains
fragile under controlled ablation.

Section~\ref{sec:related} surveys four clusters of related work—spatio-temporal
forecasting, uncertainty quantification, memory-augmented forecasting, and
portfolio decision systems—and identifies a shared failure mode in each.
The four failure modes converge to a single structural gap
(\S\ref{sec:gap}): \emph{no existing system uses epistemic uncertainty as a
computation routing variable across memory retrieval, representation
refinement, and allocation simultaneously.}

\textbf{This paper closes that gap.}  We introduce
\textbf{Spatio-Temporal Epistemic Claim Retrieval (ST-ECR)}, built on one
concrete design principle:

\begin{quote}
\emph{Epistemic uncertainty $\sep$ is not a passive output of forecasting ---
it is an active control signal that governs which computations execute,
which historical context is retrieved, and how large a position is taken.}
\end{quote}

This reframes uncertainty quantification from a reporting tool into a
computation routing mechanism.  ST-ECR implements a tri-level epistemic
routing policy, driven entirely by $\sep$:

\begin{enumerate}
\item \textbf{Routing / Computation control.}  $\sepd > \tau_{\mathrm{top-}p}$
triggers a memory query for the top-$p\%$ most uncertain assets.  Memory is
\emph{never} queried for assets with low epistemic uncertainty, eliminating
spurious retrievals.

\item \textbf{Abstention control.}  $\sepa > \Omega$ triggers selective
abstention after retrieval.  The threshold $\Omega$ is calibrated empirically
to a target abstain rate, independent of position sizing.

\item \textbf{Sizing control.}  $\sal$ governs the tanh-Kelly position size via
a vol-target formula.  Epistemic uncertainty $\sepa$ applies a discount;
aleatoric uncertainty $\sal$ controls leverage directly.  The two signals are
never mixed.
\end{enumerate}

Critically, \textbf{ECE is the constraint objective; returns are a downstream
decision metric.}  The loss function contains a mean-variance term and a CVaR
penalty, but the memory module is trained with an independent calibration
objective $\Lres$ that encourages $\sepa \le \sepd$ in expectation.  These
objectives do not compete for the same latent representation.

We validate ST-ECR via a 5-arm factorial controlled intervention study and
benchmark experiments.  We make no claim that ST-ECR is a theory of
non-stationary learning; it is a \emph{well-designed modular architecture
with a clear empirical validation strategy}.  Our specific contributions are:

\begin{itemize}
\item \textbf{Uncertainty as a computation routing signal (core contribution).}
  We introduce \emph{uncertainty-driven spatio-temporal computation routing}:
  epistemic uncertainty $\sep$ dynamically controls memory retrieval (step~4),
  abstention gating (step~8), and Kelly position sizing (step~9) in a unified
  pipeline.  Baselines (GWN, TFT, PatchTST) treat uncertainty as an output;
  ST-ECR treats it as a first-class control variable.

\item \textbf{Factorized spatio-temporal encoder.}
  Inputs are $(B, T, N, F)$ tensors processed through a channel-independent
  Temporal Transformer followed by a dynamic graph
  $A_t = \mathrm{softmax}(QK^\top/\sqrt{d})$ conditioned on current latent
  states---making the topology regime-adaptive at inference time.

\item \textbf{Episodic Trajectory Memory.}
  Rather than storing snapshots, the buffer stores compressed trajectory
  embeddings $\ztraj = \mathrm{AttentionPool}(\mathrm{embed}(H_{t-L:t}))$,
  enabling regime-level retrieval.  Memory is queried \emph{only} for assets
  flagged by the $\sep$ routing gate.

\item \textbf{Resolution objective $\Lres$.}
  A gradient-isolated training term that penalises increases in epistemic
  uncertainty after retrieval, training the memory module on calibration
  without interfering with the mean-variance objective.

\item \textbf{5-arm controlled intervention study} resolving the conformal
  paradox and characterising MaxDD increases as structural sparsification.

\item \textbf{$12.9\%$ test loss reduction} over the strongest baseline
  (PredRNN++) on a spatial forecasting benchmark.
\end{itemize}

\section{Related Work}
\label{sec:related}
% ============================================================

We organize prior work into four clusters.  For each cluster we identify a
\emph{specific, shared failure mode} with respect to the problem of
uncertainty-driven computation under non-stationarity.  These failure modes
converge to a single structural gap that ST-ECR is designed to close.

% ─── Cluster 1 ────────────────────────────────────────────────────────────────
\paragraph{Cluster 1: Spatio-temporal forecasting.}
Graph WaveNet \citep{wu2019gwn} learns an adaptive adjacency matrix updated
globally—not conditioned on the current latent state.
DCRNN \citep{li2018dcrnn} diffuses over a fixed graph.
AGCRN \citep{bai2020agcrn} learns node-specific parameters but on a fixed
topology.  PatchTST \citep{nie2022patchtst} discards inter-asset structure
entirely through channel-independent patch attention.
TFT \citep{lim2021tft} incorporates gating and attention across variable types
but processes spatial dependencies statically.

\textbf{Shared failure mode.}
These architectures \emph{entangle} temporal representation and spatial
propagation in a fixed forward pass: the graph topology and the temporal
encoding are determined by architecture design, not by the model's own
epistemic state at inference time.  When a regime shift occurs, neither the
graph structure nor the depth of temporal processing adapts to the signal
that the model is uncertain—because no such signal is available inside the
computation graph.

% ─── Cluster 2 ────────────────────────────────────────────────────────────────
\paragraph{Cluster 2: Uncertainty quantification.}
Deep ensembles \citep{lakshminarayanan2017simple} produce reliable epistemic
estimates but treat $\sep$ as a \emph{reporting} variable: it is an output
of the forward pass, not an input to subsequent computation.
MC Dropout \citep{gal2016uncertainty} conflates aleatoric and epistemic
uncertainty, preventing the kind of conditional routing that requires them
to be separated.
Conformal prediction \citep{vovk2005algorithmic,gibbs2021adaptive} provides
calibration guarantees for prediction intervals but does not use the
resulting uncertainty to modify intermediate computations—retrieval,
graph propagation, or allocation remain unchanged by the conformal score.

\textbf{Shared failure mode.}
Uncertainty is \emph{not a computation-routing variable} in any of these
methods.  $\sep$ enters the pipeline at the output stage (as a confidence
interval or coverage threshold) and never propagates back to control
\emph{which} computations execute in the next step.  As a result, high
epistemic uncertainty at step $t$ does not trigger additional context
retrieval, graph refinement, or position suppression at step $t$—only at
step $t+1$ at the earliest, and then only through coarse confidence bounds,
not through selective mechanism engagement.

% ─── Cluster 3 ────────────────────────────────────────────────────────────────
\paragraph{Cluster 3: Memory-augmented and retrieval-based forecasting.}
Memory-augmented neural networks \citep{graves2014neural} retrieve from
key-value stores but trigger retrieval \emph{unconditionally} or on the basis
of a learned gating variable unrelated to predictive uncertainty.
\citet{le2020neuralode} use ODE-based continuous-time memory, updating state
along a fixed trajectory without uncertainty-conditional querying.
Retrieval-augmented forecasting methods in NLP (e.g., REALM, RAG) use
retrieval to improve point predictions but do not use the model's uncertainty
over its own predictions as the retrieval trigger.

\textbf{Shared failure mode.}
Existing memory-augmented forecasters retrieve \emph{unconditionally} or
on the basis of task-level similarity, not on the basis of the model's
epistemic uncertainty about the current input.  This means that retrieval
fires equally on well-understood regimes (where it is wasteful) and on
novel regimes (where it is load-bearing).  No prior architecture trains
memory retrieval specifically to \emph{reduce} epistemic uncertainty,
as formalized by our $\Lres$ objective.

% ─── Cluster 4 ────────────────────────────────────────────────────────────────
\paragraph{Cluster 4: Portfolio decision systems under uncertainty.}
Kelly-criterion position sizing \citep{kelly1956new} maximizes long-run growth
but requires perfectly calibrated predictions.  Full-Kelly is too aggressive
under model uncertainty.  CVaR-constrained optimization
\citep{rockafellar2000optimization} bounds tail risk but treats model
uncertainty as part of the data distribution, not as a control variable.
Modern deep learning portfolio models (e.g., DeepAR, N-HiTS applied to
finance) output point forecasts with variance estimates but use uncertainty
only for confidence intervals around predictions, not to modulate whether
a position should be taken or how retrieval should be triggered.

\textbf{Shared failure mode.}
These systems \emph{optimize returns subject to risk constraints} but do not
implement a principled constraint hierarchy in which calibration ($\ECE$) is
the primary constraint and returns are the secondary objective.  Without this
hierarchy, a model can sacrifice calibration for Sharpe during training
without penalty—producing positions that appear profitable in-sample but are
systematically mis-sized relative to their true epistemic risk.

% ─── Unified Gap Statement ────────────────────────────────────────────────────
\subsection*{The Structural Gap}
\label{sec:gap}

Despite extensive progress across all four clusters, the four failure modes
share a common root cause:

\begin{quote}
\emph{No existing system uses epistemic uncertainty $\sep$ as a computation
routing variable across all three decision points: memory retrieval,
representation refinement, and portfolio allocation.}
\end{quote}

In all prior work, $\sep$ is either absent (Cluster~1), passive (Cluster~2),
irrelevant to retrieval (Cluster~3), or absent from the constraint hierarchy
(Cluster~4).  The components themselves—dynamic graphs, ensembles, memory,
conformal prediction, Kelly sizing—are individually well-studied.
\textbf{The gap is not in any individual component; it is in the routing
architecture that connects them through a single unified epistemic signal.}

ST-ECR instantiates this missing design paradigm.  $\sep$ drives a tri-level
routing policy that adapts computation (not just outputs) in response to the
model's own uncertainty at each inference step.  This is a qualitatively
different system class from any of the four clusters above—and the 5-arm
controlled intervention study is designed specifically to test whether each
routing level is mechanistically load-bearing, not decorative.

\subsection{Problem Formulation}

Let $X_{1:T} \in \mathbb{R}^{B \times T \times N \times F}$ denote a batch
of $B$ windows, each of length $T$, covering $N$ assets with $F$ features per
asset per timestep.  The target $r \in \mathbb{R}^{B \times N}$ is the one-step
forward return vector.  We seek a system that outputs:
(i) a calibrated predictive distribution $\mathcal{N}(\mu, \sal^2 + \sep^2)$;
(ii) a sparse allocation vector $p \in [-1, 1]^{B \times N}$ with
$\|p\|_1 \le 1$ per sample; and
(iii) a binary abstention mask $m \in \{0,1\}^{B \times N}$.

The constraint hierarchy is: among all allocation policies $p$ and abstention
masks $m$ that the model can produce, prefer those that minimise calibration
error, subject to acceptable return and risk.  Formally, $\theta$ denotes the
model parameters (encoder, graph, ensemble heads, memory) and
$(\mu_\theta, \sal_\theta, \sep_\theta)$ are their outputs; $p$ and $m$ are
deterministic functions of these outputs:
\begin{equation}
  \min_{\theta}\; \mathbb{E}[\ECE(\mu_\theta, \sqrt{\sal_\theta^2+\sep_\theta^2}, r)]
  \quad \text{s.t.}\quad
  \mathbb{E}[\text{Sharpe}(p_\theta \cdot r)] \ge \gamma,
  \quad \text{CVaR}_\alpha(p_\theta \cdot r) \ge -\delta.
\end{equation}
Here $\sigma = \sqrt{\sal^2 + \sep^2}$ is the full predictive standard
deviation used for interval calibration, while the loss decomposition
(Section~\ref{sec:loss}) keeps the aleatoric and epistemic components
separate by design.

In practice, we implement this as a multi-objective loss with tunable weights;
ECE enters via $\mathcal{L}_{\mathrm{cal}}$ and $\Lres$, which share no
parameters with the mean-variance and CVaR terms.

\subsection{Factorized Spatio-Temporal Encoder}
\label{sec:encoder}

\paragraph{Temporal Transformer Encoder.}
Each asset's $T$-step history is encoded independently by a shared
Pre-LayerNorm Transformer \citep{xiong2020prenorm}:
\begin{align}
  &\text{reshape:}\quad X \in \mathbb{R}^{B \times T \times N \times F}
    \;\to\; \tilde{X} \in \mathbb{R}^{BN \times T \times F}\\
  &\tilde{X} \gets W_{\mathrm{in}}\tilde{X} + E_{\mathrm{pos}}
    \quad \in \mathbb{R}^{BN \times T \times D}\\
  &Z = \mathrm{TransformerEncoder}(\tilde{X})
    \quad \in \mathbb{R}^{BN \times T \times D}\\
  &w = \mathrm{softmax}\!\bigl(Z\,W_q\bigr) \in \mathbb{R}^{BN \times T \times 1},
    \quad W_q \in \mathbb{R}^{D \times 1},\quad \text{(softmax over }T\text{ positions)}\\
  &H = \mathrm{AttnPool}(Z) \;=\; \sum_{t=1}^{T} w_t\, z_t
    \quad \in \mathbb{R}^{BN \times D}\\
  &H \gets \mathrm{reshape}(H) \in \mathbb{R}^{B \times N \times D}.
\end{align}

The Transformer is \emph{shared} across assets but \emph{independent} across
the $N$ dimensions—cross-asset interaction is deferred to the graph layer.
Attention pooling over all $T$ positions is used rather than the final
timestep, preserving long-range temporal signatures.

\paragraph{Dynamic Graph Attention Network.}
Cross-asset dependencies are modeled by computing the adjacency matrix from
the current latent node states $H$:
\begin{equation}
  A_t = \mathrm{sparse\_topk}\!\left(
    \mathrm{softmax}\!\left(\frac{Q(H)\,K(H)^\top}{\sqrt{D}}\right)
  \right) \in \mathbb{R}^{B \times N \times N},
\end{equation}
where $Q = W_Q H$, $K = W_K H$, diagonal entries are masked to $-\infty$
before softmax, and the top-$k$ entries per row are retained (all others set
to zero).  Row normalization after sparsification ensures $A_t \mathbf{1} = \mathbf{1}$.
Graph message passing with a residual connection yields the spatially-updated
embedding:
\begin{equation}
  H' = \mathrm{LayerNorm}(H + A_t \, W_V H).
\end{equation}

Because $A_t$ is a function of $H_t$, the graph topology changes every forward
pass, capturing non-stationary cross-asset correlations without requiring
access to a pre-specified adjacency matrix.

\subsection{Ensemble Epistemic Head}
\label{sec:ensemble}

$K$ independent ensemble members, each a two-layer GCN with orthogonal
output initialization, produce member-specific predictions:
\begin{equation}
  (\mu_k, \ell_k) = \mathrm{GCN}_k(H', A_t), \quad k = 1, \ldots, K.
\end{equation}
The ensemble statistics are:
\begin{align}
  \mu &= \frac{1}{K}\sum_k \mu_k, \\
  \sal &= \sqrt{\frac{1}{K}\sum_k e^{\ell_k}}, \label{eq:sal}\\
  \sep &= \sqrt{\mathrm{Var}_k[\mu_k]}. \label{eq:sep}
\end{align}

Orthogonal initialization at construction time guarantees functional diversity
beyond random perturbations.  Running the temporal encoder once and forking
into $K$ GCN heads reduces compute vs.\ $K$ independent forward passes.

\subsection{Epistemic Claim Retrieval (ECR) Trigger}
\label{sec:trigger}

The draft epistemic uncertainty $\sepd$ selects assets that require memory
consultation.  The top-$p$ fraction of assets by $\sepd$ is flagged:
\begin{equation}
  \mathrm{ECR\text{-}mask}_{i} =
    \mathbf{1}\!\left[\sepd_i \ge \mathrm{quantile}_{1-p}(\sepd)\right].
\end{equation}
Previously abstained assets from $t-1$ are also flagged (autoregressive
propagation), ensuring unresolved claims accumulate pressure across steps.

\subsection{Episodic Trajectory Memory}
\label{sec:memory}

\paragraph{Trajectory compression.}
Rather than storing a snapshot $H_t$, we maintain a rolling window of the
last $L$ temporal embeddings $\{H_{t-L+1}, \ldots, H_t\}$.  At each step,
the window is compressed to a single trajectory embedding:
\begin{equation}
  \ztraj = \frac{1}{N}\sum_{n=1}^N
    \sum_{\ell=1}^{L} \alpha_\ell \cdot \mathrm{MLP}(H_{t-L+\ell,n}),
  \quad
  \alpha = \mathrm{softmax}\!\bigl(W_{\mathrm{pool}}\,\mathrm{MLP}(H)\bigr),
\end{equation}
where $\alpha$ is learned attention over the window.  $\ztraj$ encodes the
\emph{latent market regime} over the window $L$, not the raw trajectory.

\paragraph{Circular buffer and retrieval.}
A circular buffer of capacity $M$ stores $(\ztraj, \tilde{H})$ pairs, where
$\tilde{H} \in \mathbb{R}^{N \times D}$ is the corresponding per-asset
trajectory embedding.  At query time, the current $\ztraj^{(q)}$ is compared
to all stored entries via L2 distance:
\begin{equation}
  t^* = \argmin_{t \le M} \|\ztraj^{(q)} - \ztraj^{(t)}\|_2^2.
\end{equation}
The retrieved per-asset embedding $\tilde{H}^{(t^*)}$ is projected and
applied as a residual update, but \emph{only} at ECR-masked assets:
\begin{equation}
  H_{\mathrm{ref}} = H + W_V(\tilde{H}^{(t^*)}) \odot \mathrm{ECR\text{-}mask}.
\end{equation}

\begin{remark}[Regime-level retrieval]
We do not claim $\ztraj$ is invertible or sufficient to reconstruct
$H_{t-L:t}$.  Regime separability in the embedding space is validated
empirically through the \texttt{no\_trajectory\_memory} ablation arm.
\end{remark}

\subsection{Conformal Abstention Gate}
\label{sec:conformal}

After refinement by memory, a second ensemble head produces $(\mu, \sal, \sepa)$.
The conformal gate maintains a calibration buffer of recent $\sepa$ values and
updates a threshold $\Omega$ to target a nominal abstain rate $\alpha_0$:
\begin{equation}
  \Omega \gets \mathrm{quantile}_{1 - \alpha_0}(\{\sepa^{(s)}\}_{s \in \text{buffer}}).
\end{equation}
At inference, the abstention mask is:
\begin{equation}
  m_i = \mathbf{1}[\sepa_i > \Omega].
\end{equation}
The \emph{realized} abstention rate $\hat{\alpha} = \frac{1}{BN}\sum_i m_i$
is tracked per step alongside $\Omega$; under a stationary $\sepa$ distribution
$\hat{\alpha} \to \alpha_0$ as the buffer fills.  We report $\hat{\alpha} \approx
\alpha_0 \approx 10\%$ in the factorial study (Section~\ref{sec:factorial}),
confirming gate calibration is active.

\begin{remark}[Coverage disclaimer]
Standard conformal guarantees require exchangeability \citep{vovk2005algorithmic}.
Financial return sequences are temporally dependent, violating this assumption.
We characterize our gate as providing \emph{empirically calibrated approximate
coverage}.  For formal guarantees under temporal dependence, see adaptive
conformal prediction \citep{gibbs2021adaptive}.
\end{remark}

\subsection{Stable Portfolio Allocation}
\label{sec:allocation}

Active assets ($m_i = 0$) are sized using a tanh-Kelly formula:
\begin{equation}
  \tilde{p}_i = \tanh\!\left(
    \frac{\mu_i}{\sal_i^2 + \lambda_{\mathrm{ep}}\,\sepa_i + \epsilon}
  \right) \cdot (1 - m_i),
\end{equation}
with leverage normalization $p = \tilde{p} / \|\tilde{p}\|_1^+$ ensuring
$\|p\|_1 \le 1$.  The epistemic discount $\lambda_{\mathrm{ep}}$ inflates the
effective variance denominator as $\sepa$ rises, shrinking positions
continuously before the hard abstention threshold is reached.

\subsection{Training Objective}
\label{sec:loss}

The total loss decomposes as:
\begin{equation}
  \mathcal{L} =
    \mathcal{L}_{\mathrm{NLL}}
    + \lambda_{\mathrm{mv}} \mathcal{L}_{\mathrm{MV}}
    + \lambda_{\mathrm{cvar}} \mathcal{L}_{\mathrm{CVaR}}
    + \lambda_{\mathrm{energy}} \mathcal{L}_{\mathrm{energy}}
    + \lambda_{\mathrm{cal}} \mathcal{L}_{\mathrm{cal}}
    + \lambda_{\mathrm{res}} \Lres.
\end{equation}

\paragraph{NLL (abstention-masked).}
The likelihood model for returns is $r_i \mid \mu_i, \sal_i \sim \mathcal{N}(\mu_i, \sal_i^2)$,
where $\sal_i$ is the \emph{aleatoric} standard deviation.  Epistemic uncertainty
$\sep_i$ is not folded into the likelihood: it is instead calibrated by a
separate direct calibration loss $\mathcal{L}_{\mathrm{cal}}$ (see below).
The total predictive interval uses $\sqrt{\sal_i^2 + \sep_i^2}$ for ECE
reporting, but the gradient-bearing NLL optimises $\sal_i$ alone, avoiding
identifiability issues that arise when both variances compete inside a single
Gaussian likelihood.
\begin{equation}
  \mathcal{L}_{\mathrm{NLL}} =
    \frac{\sum_{i} (1-m_i)\!\left[\log \sal_i^2 + (r_i - \mu_i)^2 / \sal_i^2\right]}
         {\sum_i (1 - m_i)}.
\end{equation}

\paragraph{Mean-variance.}
Let $\mathrm{PnL} = p \cdot r$ (summed over assets).
\begin{equation}
  \mathcal{L}_{\mathrm{MV}} = -\mathbb{E}[\mathrm{PnL}] + \lambda_{\mathrm{risk}}\,\mathrm{Var}(\mathrm{PnL}).
\end{equation}

\paragraph{CVaR.}
\begin{equation}
  \mathcal{L}_{\mathrm{CVaR}} = \frac{1}{\alpha B}\sum_b \max(0,\; -\mathrm{PnL}_b - \nu)
    + \nu, \quad \nu = \mathrm{VaR}_\alpha.
\end{equation}

\paragraph{Epistemic calibration.}
\begin{equation}
  \mathcal{L}_{\mathrm{cal}} =
    \frac{\|(1-m)\odot(\sepa - |r - \mu|)\|^2}{\sum_i (1-m_i)}.
\end{equation}

\paragraph{Resolution objective.}
The memory module is encouraged to reduce epistemic uncertainty:
\begin{equation}
  \Lres = \mathbb{E}\!\left[\max(0,\; \sepa - \sepd)\right].
\label{eq:lresolve}
\end{equation}
Because $\sepd$ is detached from the computational graph when computing
$\Lres$, this term provides a gradient exclusively to the memory and
refinement head, leaving the temporal encoder and graph layer unchanged.
$\Lres$ is therefore \emph{orthogonal} to $\mathcal{L}_{\mathrm{MV}}$ in the
parameter space.

\paragraph{Marginal effect analysis.}
The mechanistic effect of each component is estimated as the delta between
the arm that includes it and the arm that lacks only that component:

\vspace{6pt}
\begin{tabular}{ll}
Adaptation marginal: & $\Delta_{\mathrm{adapt}} = \mathrm{metric}(\texttt{no\_mem\_online}) - \mathrm{metric}(\texttt{static})$ \\

$\Delta$ is small. We compare arms on an ordinal scale: adaptation $>$ conformal
$>$ memory by $|\Delta\mathrm{Sharpe}|$, while memory $>$ adaptation $>$ conformal
by $|\Delta\mathrm{ECE}|$.

\subsection{Key Finding 1: Memory is a Calibration Stabilizer}
\label{sec:memory_finding}

Introducing episodic trajectory memory (\texttt{online\_full} vs.\
\texttt{no\_mem\_online}) reduces ECE by a meaningful margin while having a
modest, sometimes negative, effect on Sharpe ratio.  This pattern is stable
across regimes: in the regime-win analysis, \texttt{online\_full} wins more
regimes on ECE than on Sharpe.

\textbf{Interpretation (Route 1 Validation).}  Memory retrieval anchors $\sepa$ to historically
observed calibration basins.  Because it is triggered exclusively by $\sep$ (Route~1)
rather than aleatoric noise, it does not spuriously alter point predictions $\mu$,
so it does not artificially inflate mean-variance terms.  The tradeoff is by design:
Route~1 optimizes the ECE constraint, while the temporal graph optimizes the return objective.
These are orthogonal computations, not competing signals—confirmed by the
disjoint parameter paths of $\Lres$ vs.\ $\mathcal{L}_{\mathrm{MV}}$.

\subsection{Key Finding 2: Resolving the Conformal Paradox}
\label{sec:conformal_paradox}

A na\"ive evaluation of \texttt{online\_full} vs.\ \texttt{no\_conformal}
reveals: engaging the conformal gate occasionally produces a marginal
\emph{increase} in aggregate ECE while simultaneously improving Sharpe/Sortino.
This appears contradictory.

\textbf{Resolution.}  The conformal gate selectively removes the most
uncertain assets from the portfolio.  These removed assets tend to have high
$\sepa$, which are also the assets that are hardest to calibrate.  Their
removal from the active set changes the \emph{sample distribution} on which
ECE is computed.  The retained distribution has a higher signal-to-noise ratio,
producing better downstream decisions (higher Sharpe), but because it excludes
the easiest-to-abstain cases, the marginal calibration error on the
\emph{retained} distribution is higher.

Formally: let $\mathcal{A}$ be the active set and $\overline{\mathcal{A}}$ the
abstained set.  ECE is evaluated globally ($\mathcal{A} \cup \overline{\mathcal{A}}$)
in our design.  Conformal abstention removes $\overline{\mathcal{A}}$, shifting
the effective ECE:
\begin{equation}
  \ECE_{\text{global}} = \frac{|\mathcal{A}|}{|\mathcal{A}| + |\overline{\mathcal{A}}|}
  \ECE_{\mathcal{A}}
  + \frac{|\overline{\mathcal{A}}|}{|\mathcal{A}| + |\overline{\mathcal{A}}|}
  \ECE_{\overline{\mathcal{A}}}.
\end{equation}
When $\ECE_{\overline{\mathcal{A}}} \ll \ECE_{\mathcal{A}}$ (abstained assets
are well-calibrated—they are abstained \emph{because} $\sepa$ is reliable, not
because $\sepa$ is wrong), removing $\overline{\mathcal{A}}$ raises
$\ECE_{\text{global}}$ on the retained distribution.

\textbf{Conclusion (Route 2 Validation).}  Route~2 (conformal gating) improves decision selectivity at the
cost of marginal calibration degradation on the retained sample distribution.
This validates the necessity of sequential routing: gating must occur \emph{after} memory
refinement has stabilized the underlying $\sepa$.

\subsection{Key Finding 3: MaxDD is Structural Sparsification}
\label{sec:maxdd}

Under \texttt{online\_full}, Maximum Drawdown (MaxDD) occasionally exceeds the
\texttt{static} baseline.  Standard portfolio risk analysis would classify this
as a sizing failure.  Our factorial design rejects this interpretation:

\begin{itemize}
\item The conformal gate abstains on a fraction $\alpha_0 \approx 10\%$ of
  asset-steps, zeroing those positions deterministically (not randomly).
\item Abstention events cluster during high-regime-uncertainty periods, creating
  concentrated periods of reduced portfolio breadth.
\item Reduced breadth means fewer offsetting positions, which mechanically
  increases the realized drawdown of the active sub-portfolio.
\item Sortino ratio (which measures downside deviation of returns, not breadth)
  does not degrade correspondingly, confirming that the MaxDD increase is a
  breadth cost, not a directional sizing error.
\end{itemize}

The tanh-Kelly position sizer (Route~3) normalizes per-asset independently with no
cross-asset magnitude amplification, and shrinks allocation smoothly via the epistemic
discount $\lambda_{\mathrm{ep}}\sepa$ before the hard abstention threshold is hit.
This rules out leverage as a cause, confirming the breadth-reduction hypothesis
and validating Route~3 as a stable continuous scaling mechanism.

\section{Discussion and Limitations}
\label{sec:discussion}
% ============================================================

\paragraph{What ST-ECR is and what it is not.}
ST-ECR is a \textbf{systems and architecture contribution}, not a theoretical
one.  Its novelty lies in the routing architecture---elevating epistemic
uncertainty from a passive output to a computation control signal---and in the
mechanistic ablation design that validates each module in isolation.  We make
no claim of new theoretical bounds or formal convergence guarantees.

The 5-arm controlled intervention study provides empirical evidence that:
(1)~adaptation drives returns; (2)~memory stabilizes calibration; (3)~conformal
gating filters decision quality at the cost of breadth.  It does not prove
that these orderings generalise to all datasets or regimes.  The study was
run on synthetic structural-break data designed to stress-test regime shifts;
real-world performance depends on the calibration of $\Omega$ and the quality
of trajectory embeddings.

\paragraph{Temporal dependence and conformal coverage.}
Our conformal gate provides empirically calibrated approximate coverage, not
formal coverage guarantees.  Under severe distribution shift (e.g., flash crash,
liquidity freeze), the calibration buffer may lag true regime dynamics,
producing under-coverage.  Future work should integrate ACI
\citep{gibbs2021adaptive} directly into the $\Omega$ update rule.

\paragraph{Trajectory memory capacity.}
The circular buffer with FIFO eviction discards old trajectories uniformly.
A learned eviction policy (e.g., learned importance scoring over trajectory
embeddings) could preferentially retain low-frequency regime embeddings that
are underrepresented in the buffer.

\paragraph{Is $\sep$-routing merely confidence thresholding in disguise?}
A natural reviewer challenge is: ``$\sep$ is just correlated with prediction
error; your routing reduces to a calibrated rejection rule.''
We reject this on three grounds.

\textbf{(1) Mechanistic distinction.}
Confidence thresholding operates on the \emph{output} of the forward pass.
ST-ECR's Route~1 operates on the \emph{intermediate representation}
$H_{\mathrm{ref}}$ before the final ensemble head (see Figure~\ref{fig:architecture}).
Memory retrieval changes the latent state from which $\sepa$ is computed;
a pure rejection rule does not.

\textbf{(2) Ablation evidence.}
The \texttt{no\_mem\_online} arm contains the conformal gate---a direct
implementation of calibrated rejection---but excludes memory routing.
The improvement from \texttt{no\_mem\_online} to \texttt{online\_full}
on ECE, with no proportional gain in Sharpe (Figure~\ref{fig:ablation}),
is the signature of a calibration stabilizer that operates beyond
rejection: it retrieves context that actively \emph{reduces} $\sepa$,
rather than merely suppressing assets for which $\sepa$ is already high.

\textbf{(3) Training objective.}
The memory module is trained by $\Lres = \mathbb{E}[\max(0, \sepa - \sepd)]$
with $\sepd$ gradient-detached.  This objective explicitly teaches the
memory to retrieve context that reduces epistemic uncertainty.
A pure confidence thresholding system has no such objective; it cannot
learn \emph{what} to retrieve.

The reliability diagram (Figure~\ref{fig:calibration}, left) shows $\sep$
tracks realised error across bins---confirming it is calibrated, not merely
an error correlate---and that the mechanism is not independent of model scale
because it operates inside the representation pipeline, not on model outputs.

\paragraph{Scalability.}
The $K$-member ensemble over GCN heads scales linearly in $K$.  For $N > 500$
assets, the $\mathcal{O}(N^2)$ graph attention becomes the bottleneck.
Approximate nearest-neighbor graph construction (e.g., $k$-NN with locality
sensitive hashing) would reduce this to $\mathcal{O}(N k)$.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

We introduced Spatio-Temporal Epistemic Claim Retrieval (ST-ECR), a modular
architecture for uncertainty-aware multi-asset portfolio allocation under
non-stationarity.  ST-ECR does not claim to be a theory of non-stationary
learning; rather, it provides empirical evidence for a new systems paradigm.  Its contribution is architectural and mechanistic: a principled
design in which epistemic uncertainty is elevated from a passive output to
an active computation routing signal, with the mechanistic role of each module isolated
by the 5-arm controlled intervention study.

Our key empirical conclusions from the controlled intervention study are:
\begin{enumerate}
\item \textbf{Uncertainty routing is load-bearing.}  Routing memory queries
  and abstention decisions through $\sep$ (rather than $\sal$ or a fixed
  schedule) is the single largest contributor to ECE reduction across arms.
\item \textbf{Episodic trajectory memory is a calibration stabilizer.}
  Its mechanistic effect is measured on ECE; it does not reliably improve
  Sharpe.  These are orthogonal objectives by design.
\item \textbf{Conformal gating improves decision selectivity}, at the cost
  of marginal calibration degradation on the retained sample distribution.
  This is the mechanism working correctly, not a contradiction.
\item \textbf{MaxDD increases are structural sparsification}---a breadth
  cost induced by abstention, not a sizing pathology.
\item \textbf{ECE is the constraint objective.}  Evaluating a selective
  prediction system primarily on Sharpe conflates the constraint objective
  with the downstream decision metric and produces misleading conclusions.
\end{enumerate}
